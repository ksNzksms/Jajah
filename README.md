# نشر ركن المعرفة على الاستضافة

1. ارفع ملفات PHP ومجلدي `admin/` و`assets/` إلى مجلد الموقع في استضافتك (غالبًا `public_html`).
2. أنشئ قاعدة MySQL ومستخدمًا لها من لوحة الاستضافة، ثم امنح المستخدم صلاحية الوصول للقاعدة.
3. عدّل `config.php` وضع بيانات قاعدة البيانات. أبقِ كلمة المرور سرية ولا ترفعها إلى مستودع عام.
4. افتح `https://strampla.store/install.php` مرة واحدة وأنشئ حساب مدير بكلمة مرور طويلة وفريدة.
5. بعد نجاح الإعداد احذف `install.php` من ملفات الاستضافة.
6. لوحة الإدارة: `https://strampla.store/admin/login.php`.
7. أضف المقالات من «مقال جديد»، واستخدم حالة «منشور» ليظهر المقال للعامة.

المتطلبات: PHP 8.0+ مع PDO MySQL وامتداد mbstring، وقاعدة MySQL/MariaDB. ملفات PHP لا تعمل على GitHub Pages؛ ارفعها إلى استضافتك عبر مدير الملفات أو FTP/SFTP. لا تضع بيانات الاستضافة أو كلمات المرور في المحادثة أو مستودع عام.
